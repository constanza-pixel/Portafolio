Vue Product Showcase: Aplicación Web Dinámica y Responsiva

1. Descripción de la actividad

Desarrollo de la interfaz de usuario para un catálogo interactivo de productos con carga asíncrona, filtrado reactivo por categorías, gestión de favoritos en el cliente y soporte multi-tema (claro/oscuro).

2. Desafío principal

Evitar llamadas redundantes a la API externa al alternar filtros, previniendo retrasos en el renderizado y asegurando una navegación fluida en dispositivos móviles con conexiones inestables.

3. Solución técnica propuesta

Estructuración del estado centralizado mediante Vuex con caché local en localStorage, desacoplamiento de componentes reutilizables y carga diferida (lazy loading) en elementos multimedia.

4. Herramientas técnicas utilizadas

Vue.js (Vuex, Vue Router), Axios para consumo asíncrono de API REST, BootstrapVue / Bootstrap 5, Jest y Cypress para pruebas automatizadas, y Git/GitHub para control de versiones.

5. Principales aprendizajes

Gestión del flujo unidireccional de datos en SPA, manejo estructurado de excepciones HTTP con Axios interceptors y diseño centrado en accesibilidad (WCAG) y navegación por teclado.

6. Métricas de impacto logradas

95+ Google Lighthouse
-40% Tiempo de carga LCP
100% Diseño responsivo

7. Habilidades técnicas aplicadas

Arquitectura Single Page Application (SPA), consumo de endpoints RESTful, modularización de estilos CSS/SASS, diseño Mobile-First y documentación técnica del repositorio en README.md.

8. Justificación de la elección

Sintetiza la culminación de la ruta técnica: integra arquitectura por componentes, pruebas, consumo asíncrono y control de estados, demostrando capacidad para construir productos web funcionales listos para producción.
